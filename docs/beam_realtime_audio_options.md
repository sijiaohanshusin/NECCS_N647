# 定向录音实时播放方案 (2026-07-15, 2026-07-19 引脚核定)

> **2026-07-22 方案 1 已实现(固件侧, 待上板)**: `app_beam_play.c` =
> I2S2 主发 48k/16bit, 时钟 PLL2→IC8/10=24.576MHz(与 SAI1 同 VCO, 采样
> 锁定), GPDMA1_Ch2 单节点循环链表 + `.noncacheable` 双半缓冲, 单声道
> 复制 L/R。两个互斥生产者喂同一 16384 样本环缓: 录音页「监听」开关
> (FeedFrame tap, ~10ms 延迟垫) 和「回放」键(媒体线程流最近一条
> AUDnnnnn.WAV, 与录制互斥)。GDB 钩子 `g_app_beam_play_test_request`
> (1=监听翻转+跳录音页, 2=回放翻转)。接线见下表(MAX98357: VIN=5V,
> GAIN/SD 悬空, 喇叭 4Ω)。为给内部 RAM 腾位, USBX regular 池挪到
> npuRAM3 0x34220000(cache 池 0x34200000 上方)。双构建零错零警;
> **板级验收待板子回实验室**(底噪/指向性/录听一致/互斥/5min 长跑)。

现状:波束成形输出是 48 kHz 单声道 int16 流(`app_beam_record` 环形缓冲),
已能写 WAV 到 SD 并经 SWD 拉取(`tools/debug/pull_audio.ps1`)。要"实时听",
需要给这条流加一个实时出口。三条路线,按推荐顺序:

## 方案 1:I2S DAC + 耳机/小扬声器(设备端监听,推荐先做)

- 硬件:PCM5102A 或 MAX98357A 模块(约 10 元)。接 3 根信号线
  (BCLK/LRCK/DIN)+ 3V3 + GND。MAX98357 直推 4Ω 小喇叭,
  PCM5102 出线路电平接耳机。
- **引脚已核定(2026-07-19, 对照拓展板网表 + CubeMX N647 库, 均为空脚)**:
  用 **I2S2**(SPI2 的 I2S 模式, 外设当前完全空闲), 三根线在 P1 排针同排相邻:

  | 信号 | MCU | 拓展板位置 | 备注 |
  |---|---|---|---|
  | BCLK | PF2 = I2S2_CK | **P1.17** | 网表上是独立空脚(仅到排针) |
  | LRCK/WS | PC1 = I2S2_WS | **P1.19** | 同上 |
  | DIN | PG8 = I2S2_SDO | **P1.21** | 同上(PD7 也可作 SDO, 但共 DCMI_D0 stub, 次选) |
  | 3.3V | - | P5 / J3.3/4 | PCM5102 用 3.3V |
  | 5V | - | P6.2/4/6 | MAX98357 建议 5V(更大不失真功率) |
  | GND | - | J3.1/2 / P10.2 | 与信号同板取地 |

  MAX98357/PCM5102 都不需要 MCLK(PCM5102 的 SCK 脚接地走内部 PLL)。
  软件不变:I2S2 TX 主模式 48k/16bit, 循环 DMA 双半缓冲喂波束环缓,
  时钟挂到与 SAI1 同源的音频 PLL 树上, 无重采样。
- 软件(~150 行):SAI2 TX 主模式 48 kHz 16bit 单声道,循环 DMA 双半缓冲,
  半传输中断从波束环缓拉数据;环缓空时填零(静音)。时钟直接复用现有
  PLL2 音频时钟树(与 SAI1 同源,天然同步,无重采样)。
- 效果:戴耳机"指哪听哪",波束扫过声源时人声/异响立刻清晰,是最直观的
  现场演示形态。延迟 < 20 ms。

## 方案 2:USB UAC 麦克风(电脑端监听,配合后续 USB 启用)

- 硬件:零改动。板上 USB3.0-C34-P 连接器的 D-/D+ 已接 OTG 控制器
  (PA4=USB1_EN 控 VBUS 开关)。
- 软件(2-4 天,主要风险在枚举调试):启用 USBX 设备栈 + UAC 1.0 音频类,
  设备枚举为"NECCS 定向麦克风";等时 IN 端点每 1 ms 推 48 样本
  (96 B/帧),数据源即波束环缓。电脑上任何录音/直播软件直接选它当麦克风,
  可实时监听也可直接录制。
- 附带收益:同一 USB 口后续可复合 MSC(U 盘模式读 SD 卡拷文件),
  取代 SWD 拉文件的慢速通道。

## 方案 3:UART 流(零硬件应急,过渡用)

- USART1(PE5/PE6)当前空闲(云台已改为 PWM 舵机方案,不占串口),
  1.5 Mbaud 可承载 48k 单声道(768 kbps 载荷 + 帧头)。PC 端 Python
  `sounddevice` 实时播放。
- 音质受波特率误码影响,仅作过渡验证。

## 采购清单(2026-07-19, 方案 1 为主 + 可选无线监听)

| 物料 | 数量 | 参考价 | 用途 |
|---|---|---|---|
| **MAX98357A I2S 功放模块** | 2(备 1) | ~10 元/个 | 喇叭外放监听, 3 线 I2S + 5V |
| **PCM5102A I2S DAC 模块** | 1 | ~15 元 | 3.5mm 耳机/线路输出, 演示戴耳机听 |
| 4Ω 3W 小扬声器(带线) | 2 | ~5 元/个 | 配 MAX98357 |
| 2.54 杜邦线/排针 | 若干 | - | P1 排针到模块 |
| (可选) KCX_BT_EMITTER 蓝牙发射模块 | 1 | ~20 元 | 接 PCM5102 线路输出 → 蓝牙耳机无线听(+100~200ms 延迟, 仅演示锦上添花) |

不建议买: USB 声卡(方案 2 用板上 USB 零硬件)、带 MCLK 需求的 DAC
(WM8960 等, 多一根时钟线无收益)、模拟 MEMS 麦克风放大板(不相关)。

## 建议

方案 1 用 P1 排针杜邦线直挂即可落地, 不动任何现有走线; USB 启用后追加
方案 2, 一口气解决"电脑实时听 + 文件快速导出"两件事。

云台/激光引脚已定稿并同步进 .ioc,见 `docs/gimbal_laser_pinmap.md`。
