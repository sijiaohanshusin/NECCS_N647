# 定向录音实时播放方案 (2026-07-15)

现状:波束成形输出是 48 kHz 单声道 int16 流(`app_beam_record` 环形缓冲),
已能写 WAV 到 SD 并经 SWD 拉取(`tools/debug/pull_audio.ps1`)。要"实时听",
需要给这条流加一个实时出口。三条路线,按推荐顺序:

## 方案 1:I2S DAC + 耳机/小扬声器(设备端监听,推荐先做)

- 硬件:PCM5102A 或 MAX98357A 模块(约 10 元)。接 3 根信号线
  (BCLK/LRCK/DIN)+ 3V3 + GND。新板走线时给 SAI2 一组引脚即可;
  MAX98357 直推 4Ω 小喇叭,PCM5102 出线路电平接耳机。
- 软件(~150 行):SAI2 TX 主模式 48 kHz 16bit 单声道,循环 DMA 双半缓冲,
  半传输中断从波束环缓拉数据;环缓空时填零(静音)。时钟直接复用现有
  PLL2 音频时钟树(与 SAI1 同源,天然同步,无重采样)。
- 效果:戴耳机"指哪听哪",波束扫过声源时人声/异响立刻清晰,是最直观的
  现场演示形态。延迟 < 20 ms。

## 方案 2:USB UAC 麦克风(电脑端监听,配合后续 USB 启用)

- 硬件:零改动。板上 USB3.0-C34-P 连接器的 D-/D+ 已接 OTG 控制器
  (PA4=USB1_EN 控 VBUS 开关)。
- 软件(2-4 天,主要风险在枚举调试):启用 USBX 设备栈 + UAC 1.0 音频类,
  设备枚举为"NECCS 定向麦克风";等时 IN 端点每 1 ms 推 48 样本
  (96 B/帧),数据源即波束环缓。电脑上任何录音/直播软件直接选它当麦克风,
  可实时监听也可直接录制。
- 附带收益:同一 USB 口后续可复合 MSC(U 盘模式读 SD 卡拷文件),
  取代 SWD 拉文件的慢速通道。

## 方案 3:UART 流(零硬件应急,过渡用)

- USART1(PE5/PE6)当前空闲(云台已改为 PWM 舵机方案,不占串口),
  1.5 Mbaud 可承载 48k 单声道(768 kbps 载荷 + 帧头)。PC 端 Python
  `sounddevice` 实时播放。
- 音质受波特率误码影响,仅作过渡验证。

## 建议

方案 1 与新板同步落地(引脚已在重画范围内);USB 启用后追加方案 2,
一口气解决"电脑实时听 + 文件快速导出"两件事。

云台/激光引脚已定稿并同步进 .ioc,见 `docs/gimbal_laser_pinmap.md`。
