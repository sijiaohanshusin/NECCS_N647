# 电源管理板首次上电 + 杜邦线联调手册

日期: 2026-07-21 · 依据: `自研电源管理板子/Netlist_电源管理.net` +
`拓展板（新）.net` 逐网核对 · 配套: `docs/gimbal_laser_pinmap.md`(改元件
清单原文) · 固件: `app_power.c`(BQ25730@I2C2 0x6B, 开机自动探测+每秒轮询,
充电电流默认 0 = 安全)

**分三阶段, 顺序不可跳**: A 电源板独立电测 → B 杜邦信号联调(N6 仍用
现有供电) → C 供电切换(电源板接管整机 5V)。杜邦方案天然回避了
FPC 排线"剪 18/19 芯"的问题——两板 3.3V 之间**不拉线**即可。

## 〇、接口速查(网表提取, 已核对)

### 电源板

| 接口 | 类型 | 引脚 → 信号 |
|---|---|---|
| **H1** | 1x11P 2.54 排针(杜邦主战场) | 1=ENB2 · 2=ENB1 · 3=ENA2 · 4=**ENA1(禁接!)** · 5=PG · 6=CMPOUT · 7=OTG/VAP · 8=CHRG_OK · 9=SCL · 10=SDA · 11=PROCHOT |
| H2 | 1x3P 排针 | 全部 = VSYS(电池/系统母线, 测试点) |
| **H3** | 1x2P 跳线 | 1=VSYS ↔ 2=U3(5V buck)输入 → **插帽=5V 轨上电** |
| **H4** | 1x2P 跳线 | 1=VSYS ↔ 2=U5(7.4V buck)输入 → **插帽=7.4V 轨上电** |
| CN2 | XH2.54 | 1=**BATT+**(4S 电池) 2=GND |
| CN3 | XH | 1=VSYS 2=GND |
| CN4 / CN5 | XH | 1=5V 2=GND(阶段 C 供整机) |
| CN7 | XH | 1=7.4V 2=GND(舵机电源) |
| CN1 / MIC / LASER / BQ | XH | 1=3.3V**激光轨**(U6 输出) 2=GND — 只准接激光 |
| USB1 | Type-C | PD 适配器输入(CH224A 诱骗) |
| USB3 / U8 | USB3-A 座 / GH-8 | 云台线束(7.4V+PWM, 见 §五) |
| LED | 指示灯 | LED1=5V 轨 · LED4=7.4V 轨 · LED2+LED3=3.3V 激光轨(U4 不贴, 两颗同轨) |

H1 方向自检(接线前必做, 蜂鸣档): **H1-1 ↔ U6 第 1 脚(EN)** 导通、
**H1-10 ↔ U1(BQ25730) 第 12 脚(SDA)** 导通, 两条都对才算认对了方向。

### 拓展板(杜邦落点, 全部 2.54 排针)

| 信号 | 落点 | MCU 引脚 |
|---|---|---|
| I2C2_SCL | **P1-2** | PD14 |
| I2C2_SDA | **P1-4** | PD4 |
| CMPOUT | **P1-13** | PH8(内部上拉已启) |
| CHRG_OK | **P2-35** | PH5(内部上拉已启) |
| PG | **P2-34** | PB3 |
| ENB2(激光) | **P2-4** | PC10 |
| PAN PWM | **P1-10** | PE13(TIM1_CH3) |
| TILT PWM | **P1-9** | PE14(TIM1_CH4) |
| OTG/VAP(可选) | J3-11 | PD13 |
| PROCHOT(先不接) | P1-27 | PD3(与蜂鸣器共线) |
| 5V 输入 | **P6**(1/3/5=GND, 2/4/6=VCC5) | - |
| GND | P6-1/3/5 | - |

ENB1(PC7)在拓展板上**没有排针破出**(只到核心板座 J1-137 和 FPC 座
10 脚)→ 杜邦阶段**不接**。后果: U5 的 EN 悬空 = 自启(TPS5450 内部
上拉), 7.4V 轨常开、LED4 常亮; 插着的舵机上电瞬间可能轻微抖动;
固件拉 PC7 无实际作用但无害。最终 FPC 上机后恢复轨门控。

## 一、阶段 A: 电源板独立电测(不连 N6)

### A0 上电前核对(万用表, 焊接完成 ≠ 改动落实)

改值清单(出图 BOM 是错的, 必须逐项确认):

| 位号 | 应装值 | 装错的后果 |
|---|---|---|
| R30/R31/R33 | 30.9k / 0Ω / 10k | 5V 轨只出 **1.83V**, 整机起不来 |
| R40/R41/R43 | 51k / 0Ω / 10k | 7.4V 轨只出 1.83V |
| R37/R38 | **16.5k** / 10k | 激光轨只出 2.48V, 激光亮不透 |
| R26/R27 | 1.5k/4.7k(或 4.7k/14k) | CELL 判串落死区, BQ 充电压不定 |
| R16-R20, R29 | **全部拆除** | 上拉挂在激光轨上, 轨断电时把 I2C2 拖到半电平 → 麦阵/触摸/相机全故障(07-18 夜已吃过一次亏) |
| U4 | **不贴** | 与拓展板 AMS1117 互灌 |
| U6 EN | 100k→GND 已加 | 复位窗激光乱亮 |
| 拓展板 R14 | **拆除** | MCU 复位期 ENB2 被上拉 = 一上电激光就亮 |

电阻档量对地阻抗(判短路, >1kΩ 为正常): H2(VSYS)、CN4(5V)、
CN7(7.4V)、CN1(3.3V)各对 GND。

### A1 首次上电(强烈建议可调电源代替电池)

可调电源 12-16V、**限流 0.5A**, 接 CN2(极性: 1=+, 插前用表核对 XH
压线!)。H3/H4 跳线帽**都不插**。
预期: 静态电流 < 50mA; H2 量 VSYS ≈ 输入电压; 四颗 LED 全灭。

### A2 5V 轨

插 H3 跳线帽 → LED1 亮, CN4 量 **5.00V ±5%**。
量到 1.83V = R30/R31/R33 没改(回 A0 表第一行)。

### A3 7.4V 轨

插 H4 跳线帽 → LED4 亮(ENB1 悬空自启), CN7 量 **7.4V ±5%**。
量到 1.83V = R40/R41/R43 没改。

### A4 激光轨(手动预测试)

H1-1(ENB2)经一颗 **10k 电阻**跳到 CN4 的 5V → LED2/LED3 亮,
LASER 座量 **3.30V**; 拔掉跳线 → 轨灭(靠 100k 下拉)。
量到 2.48V = R37 还是 10k。

### A5 换真电池复测

4S 包(16.8V 满)接 CN2, 重复 A2-A4 量三轨。
到此电源板本体合格。

## 二、阶段 B: 杜邦信号联调(N6 保持现有供电)

### B0 接线(全部断电下进行)

**共地先行**: 电源板 CN3-2 或 CN4-2 (GND) → 拓展板 P6-1 与 P6-3,
**两根**。然后按下表(8 根信号线):

| # | 电源板 | 拓展板 | 备注 |
|---|---|---|---|
| 1 | H1-9 (SCL) | P1-2 | I2C2 |
| 2 | H1-10 (SDA) | P1-4 | I2C2 |
| 3 | H1-8 (CHRG_OK) | P2-35 | 开漏, MCU 内部上拉 |
| 4 | H1-6 (CMPOUT) | P1-13 | 同上 |
| 5 | H1-5 (PG) | P2-34 | UCPD 电源好 |
| 6 | H1-1 (ENB2) | P2-4 | 激光轨门控 |
| 7 | H1-7 (OTG/VAP) | J3-11 | 可选, 不测 OTG 可不接 |
| 8 | H1-11 (PROCHOT) | - | **先不接**(与蜂鸣器共线, 状态走 I2C 读) |

**永远不接**: H1-4 (ENA1, 悬空=自启, 接电池=烧 TPS5430)、
H1-3 (ENA2, U4 不贴)、H1-2 (ENB1, 无落点, 悬空=7.4V 常开)。

### B1 上电与基线确认

顺序: 先电源板(电池), 后 N6。然后:

```powershell
cd D:\Project\NECCS\Program\NECCS_N647
.\tools\debug\n647.ps1 status        # pcmd 必须仍 present=0xf cfg_ok=0xf
```

pcmd 变差 = I2C2 被新接线拖坏 → 立即拔 SDA/SCL 两根线复测,
再查 R17/R18 是否真的拆了、线是否插错排。

### B2 BQ25730 探测

```powershell
.\tools\debug\power_dbg.ps1
```

| 字段 | 预期 | 不对时查 |
|---|---|---|
| `probe` | 0 | SDA/SCL 对调? 共地没接? |
| `mfg/dev` | 0x40 / 0xD5 | 同上 |
| `vbat` | ≈ 电池实际电压 | ADC_VALID flag(0x002) |
| `vsys` | ≈ VSYS | - |
| `soc` | 按 4S 曲线合理 | R26/R27(CELL 判串) |

BQ 是开机探测的: 接好线后要**重启一次固件**(`n647.ps1 flash-debug
-SkipBuild` 或按复位)再读。

### B3 充电链路

PD 适配器插电源板 USB1 → 再跑 `power_dbg.ps1`:
`pins` 的 CHRG_OK 位(0x02)置位, `chg_status` 非零, PG 位跟随。
量 VBUS 实际电压(CH224A 由 CFG 电阻决定档位, 固件 I2C 控压尚未实现)。

**充电电流默认 0**, 放流用 GDB 钩子(2026-07-21 加入, 上限钳位
2048mA, BQ 看门狗 175s 由固件每 60s 自动续写):

```powershell
.\tools\debug\gimbal_test.ps1 charge -Ma 512   # 请求 0.5A 充电
.\tools\debug\gimbal_test.ps1 charge -Ma 0     # 停充
```

回读 `dirty=0` = 已写入 BQ 成功; `dirty=1` 挂着 = I2C 没通(查 B2)。
首次灌流从 256/512mA 起步, 盯电池温度与 `ibat` 读数。

### B4 激光

激光头插 LASER 座。一条命令翻转(内部自动先抬 7.4V 轨再开 U6):

```powershell
.\tools\debug\gimbal_test.ps1 laser    # 再跑一次=关
.\tools\debug\gimbal_test.ps1 state    # 随时查: 固件状态+PC7/PC10 实际电平
```

预期: `rail_on=1 laser=1 PC7=1 PC10=1`(已板验) → LED2/LED3 亮 →
LASER 座 3.3V; 关闭后轨压掉到 0(100k 下拉在, 且拓展板 R14 已拆)。

### B5 舵机

舵机电源: CN7(XH)取 7.4V/GND(杜邦阶段该轨常开); 信号:
PAN←P1-10、TILT←P1-9(共地已通)。

```powershell
.\tools\debug\gimbal_test.ps1 center                 # 使能+走中位(1500µs)
.\tools\debug\gimbal_test.ps1 point -Theta 20 -Phi -10   # 指定角度(度)
.\tools\debug\gimbal_test.ps1 enable                 # 使能开关翻转
```

注意 F3(0603 保险丝)整条 7.4V 都过它, 双舵机堵转会超——大负载
测试前按 pinmap 文档换 ≥3A 或 0Ω。

## 三、阶段 C: 供电切换(A+B 全绿后才做)

1. **先断开 N6 现用的 5V 供电**(双 5V 源绝对禁止并联)。
2. CN4 + CN5 → P6: 至少 **3 对** 5V/GND 杜邦短线(单根杜邦按 1A 算,
   整机 5V ≈ 2A), 更稳妥是焊 XH-杜邦粗线。
3. **工作流影响**: 整机改电池供电后, H7 继电器不再能断板电 →
   `n647.ps1` 的烧写断电序列失效。对策: 把 H7 继电器串进 CN2 电池线
   或 CN4→P6 的 5V 线里, 保住远程断电能力。
4. 验收: 冷启动 5 次, 每次 `status` 全绿 + 声学自检 PASS。

## 四、红线汇总(出事都是大事)

1. **ENA1(H1-4)不接任何东西**。TPS5430 EN 绝对最大 7V, 电池 16.8V
   一触即烧。悬空=自启, 正是需要的行为。
2. **双 5V 源禁止并联**(阶段 C 第 1 条)。
3. **R17/R18 必须已拆**再连 I2C——否则激光轨一断电整条 I2C2 半电平,
   麦阵/触摸/相机集体故障, 且症状像"时好时坏"极难查。
4. XH 线极性插前必量(压线厂反线不罕见)。
5. LASER/CN1/MIC/BQ 四个座 = 激光轨专用, 麦阵等负载不得从电源板取电。

## 五、云台正式线束(后续, 非杜邦阶段)

USB3-A 口: 1=7.4V, 5=PAN, 6=TILT, 9=激光 3.3V, 4/10-13=GND;
GH-8(U8): 1=7.4V, 3=PAN, 4=TILT, 6=GPIO4(继电器), 8=激光 3.3V。
转接板设计要点见 `gimbal_laser_pinmap.md` §五(PWM 下拉、储能电容、
F3 扩容、丝印警示)。
