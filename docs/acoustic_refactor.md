# 声源定位重构 (2026-07-19)

一句话: 把架构从"低速率估计 + UI 层惩罚性门控"改回 H7 验证过的
"高速率估计 + 跟踪器平滑", 四类症状(响应慢/指示不到/伪影/不平滑)对症修复。

## 一、重构前根因(板上实测 + H7 对照)

| 根因 | 证据 |
|---|---|
| SRP 有效速率 4.5fps(叠加时), 目标 20 | srpbench 基线: total 67-115M cycles/帧, coarse+fine 占 ~95% |
| SRP 线程优先级全场最低(14), 相机 worker(13) 抢 HyperRAM | 注释+实测: 叠加把 SRP 从 7 压到 3-4fps |
| UI 双帧一致 @ 3-7fps = 300-600ms 锁定延迟; 拍手只产生 1-2 帧 → 门不开 | Model.cpp 旧 source-lock 逻辑 |
| 2s 冻结保持 → "声音变了准心还在原地" | 同上 |
| 坏麦 M31 未进 bad_channel_mask, 零通道进 160 对互谱 | 默认 mask=0, 基线探针 mask=0xffffffff |
| BALANCED 静默降级 B24→B16(±30° 角跳的历史祸首) | 基线探针 bins=16, resolver 与 9d68b8e6 定稿不一致 |
| 场 EMA 固定 α 按 7fps 整定 | 15-25fps 下衰减每秒慢 3 倍 → 拖尾 |

## 二、新架构

```
采集 187.5Hz (不动)
  → SRP 线程 (prio 13, 与相机 worker 1-tick 时间片轮转)
      互谱 Welch EMA (β=0.5, PHAT 前, 跨帧提 SNR/压单帧旁瓣)
      滞后域 GCC 引擎: 每对在物理 TDOA 窗内合成相关行
        (bins×lags cos/sin 表, MVE-ready), 网格点 = 每对一次插值查表
      粗 9×9 → top3 精搜 (搜索结构不变, 内核换掉)
  → app_acoustic_tracker (新增)
      双轴恒速 Kalman (量测噪声按质量加权)
      25° 关联门 + 双估计一致重播种(70-130ms) + q_margin≥6 瞬态快路径
      置信度积分: 仅"关联上"的帧计分(质量=超出模式门限的裕量),
        0.30 开/0.12 关滞回, 全静 ~0.9s 落地
  → 显示
      场 EMA 改时间常数定义 (attack 60ms / decay 350ms, DWT dt 换算)
      叠加 alpha × 置信度淡入淡出 (12%→35% 置信度线性)
      Model.cpp 旧门控全部退役, 准心/卡片/热斑同一置信度权威
```

## 三、板上结果 (Wide32 STANDARD, 叠加开)

| 指标 | 重构前 | 重构后 |
|---|---|---|
| SRP 帧 CPU | 88M cycles (~110ms) | **~16M cycles 中位 (~20-30ms 墙钟)** |
| SRP 速率 | 4.5fps (叠加) / ~7 (无) | **15-20fps (叠加+markers)** |
| 锁定延迟 | 300-600ms+ | 置信度 2-3 帧 ≈ **130-200ms**; 强瞬态单帧 |
| 准心行为 | 2s 冻结/跳变 | Kalman 连续轨迹 + 0.5-0.9s 平滑衰减 |
| 静室幻影 | Core16 曾 conf=85 | **conf=0**(关联制计分修复) |
| 合成自检 | 无运行时通道 | GDB 钩子 `g_app_acoustic_selftest_request`, **PASS** |

自检顺带揪出两个存量 bug: 滞后窗按最大基线而非转向表角点定尺寸(角点
TDOA 可超 baseline/c, 边缘钳位毁粗面); 合成信号发生器 dy 没跟上
9d68b8e6 的相机上下翻转(φ 镜像)。

## 四、遗留 / 下一步

1. **编译选项**: 全工程 `-mfpu=fpv5-d16` 关闭了 Helium/MVE, 相关行合成的
   MVE 内联走的是标量回退。改 `.cproject` FPU 选项预计再拿 2-4×(FFT/相关
   行), 但要全项目回归, 单独一次做。
2. 模式切换瞬间 failed_frames 会累计若干(几何不匹配的过渡帧, 原有行为),
   稳态为零; 可在切换窗口静默丢弃。
3. 现场整定(需要真声源): 首指示延迟/角抖动 RMS/拍手可见时长/移动源
   连续性; 参数集中在 `app_acoustic_tracker.c` 顶部 TRK_* 与
   `app_acoustic_service.c` 的 FIELD_*_TAU。
4. `srpbench`/`trackbench`/`selftest`/`core16_cycle` GDB 脚本在
   `_debug_logs/`, 复测直接用。

## 五、验收清单(现场, 需要人 + 声源)

- [ ] 手机播 1kHz: 出声到准心+热斑 ≤200ms; 静止源准心抖动 ≤3°
- [ ] 拍手: 单次拍手必有可见指示, 持续 ≥0.8s
- [ ] 移动源(手机划弧): 准心连续跟随, 无 2s 冻结、无跳变
- [ ] 关声源: 热斑 ~0.5s 内淡出(非突然消失), 准心随后消失
- [ ] 静室: 无幻影热斑/准心(Wide32 与 Core16 各观察 1 分钟)
- [ ] 双源(两部手机隔 >30°): 主源准心稳定, S2 标记出现
